## 🚀 Projects 

### 🕶️ ACPI (Crossing Assistant for the Visually Impaired) ~ Contributor
> A hardware and software system developed to assist visually impaired individuals in crossing streets safely and autonomously.

*   **My Contribution:** Upgraded the system's autonomy by integrating key sensors (accelerometer/magnetometer) to dynamically orient the user toward the correct direction, backed by real-time haptic motor feedback.
*   **Tech Stack:** `C/C++` & `Kotlin`
*   **Keywords:** Hardware Design, Embedded Systems, Social Impact
